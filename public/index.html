📖 游戏玩法

🎯 游戏目标

传牌是一款多人喝酒惩罚纸牌游戏。每局由上局输家指定"第几大输"，所有人各拿2张牌，轮流传牌后比大小，排名对应的玩家即为本局输家，需要接受惩罚（喝酒）。

🔄 游戏流程

  1. 指定名次 — 输家指定本轮"第几大喝"（可多选）
  2. 发牌 — 每人发2张牌
  3. 传牌 — 从输家开始，按顺序每人选一张牌传给下家
  4. 选规则 — 最后拿到牌的人从三种玩法中选一种
  5. 结算 — 根据所选规则比较大小，排名对应者即为输家

🃏 三种玩法

三匹

比牌面大小。牌型从大到小：
对子 ＞ 同花顺 ＞ 同花 ＞ 顺子 ＞ 高牌
同牌型比点数，点数相同比花色（♠＞♥＞♣＞♦）
出对子 → 倍数+1

10点半

两张牌点数相加，最接近10.5的最大。
A=1, 2-10按面值, J/Q/K=0.5
超过10.5为暴牌（最小）
恰好10.5 → 倍数+1

捞腌菜

两张牌点数相加，取个位数比大小。
A=1, 2-9按面值, 10/J/Q/K=0
个位数9最大，0为"睡着"（最小）
非0且对子或同花 = "双腌" → 倍数+1

⚡ 倍数惩罚

触发特殊牌型（对子/10点半/双腌）的玩家会使全局倍数累加，输家最终惩罚 = 基础惩罚 × 总倍数。
触发者如果自己输了，还会额外+1倍惩罚！
